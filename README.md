# HisabNikash — public distribution bundle

This directory is the complete allowlist for the separate public repository `mdnhsiam/hisabNikash-public`: these static pages, stylesheet, brand logo, this README and `.nojekyll`. The existing source repository/history stays private. No APK is included until owner signing and device acceptance are complete. No production download is claimed.

Core app use is free, offline and has no ads/subscription. Current public candidate offers local encrypted folder backup and readable PDF export. Public Google Drive is unavailable until production OAuth/certificate/provider testing is complete. A user's document provider may have its own storage/charges; this app buys nothing for them.

GitHub public releases can distribute the final APK; GitHub Pages can host these static information pages under GitHub Free within service limits. Keep APKs in release assets, not Pages/source history. No paid domain, paid Actions, server, card or billing linkage is needed for this path. Play/Android full-distribution registration is not included because it costs money. Country/device sideload requirements may still apply.

## Before enabling a download

1. Owner creates/backups a release keystore outside source and signs using the local helper or Android Studio. Never upload the key/password.
2. Verify exact non-debug certificate, package, version, min/target, APK digest, alignment and actual phone tests including backup/restore and native PDF.
3. Owner confirms the exact public-only repository/page/APK exposure. Do not change private source visibility.
4. Publish the signed APK with checksum/certificate and tested limitations. Replace the pending notice in `index.html` with the verified release link and update this page's status. Do not link a debug build as production.
5. Enable Pages only after reviewing these policy/support contents. Static pages collect no user data; the hosting provider handles normal web requests under its policy. No Google OAuth domain ownership is claimed merely by preparing files.
