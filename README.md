## Before enabling a download

1. Owner creates/backups a release keystore outside source and signs using the local helper or Android Studio. Never upload the key/password.
2. Verify exact non-debug certificate, package, version, min/target, APK digest, alignment and actual phone tests including backup/restore and native PDF.
3. Owner confirms the exact public-only repository/page/APK exposure. Do not change private source visibility.
4. Publish the signed APK with checksum/certificate and tested limitations. Replace the pending notice in `index.html` with the verified release link and update this page's status. Do not link a debug build as production.
5. Enable Pages only after reviewing these policy/support contents. Static pages collect no user data; the hosting provider handles normal web requests under its policy. No Google OAuth domain ownership is claimed merely by preparing files.
